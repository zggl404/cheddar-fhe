# 48 GB GPU：Keyswitch 计时、KMS 与 Hybrid 拆分验证

2026-10-30。全部十个模型均完成真实 GPU 密文整网的 A–F 功能矩阵，保持原有逐层 1e-2 数值门槛。
最终矩阵共 **85 个成功配置、225 次完整推理**（包含预热和容量探测）。同一批图片重复用于不同配置，不表示进行了等量独立测试集抽样。

| 配置 | 密钥模式 | 计时采集 | Hybrid 拆分 |
|---|---|---|---|
| A | generate | off | off |

| C | load | off | off |

## 方法与取舍

- 采用同步 scope 测量，不引入 CUPTI；关闭时不新增采集同步。采集会扰动 CPU/GPU 重叠，详见[计时边界](keyswitch-profiling.md)。
- 拆分执行是真实独立 ModDown/Rescale、KeyMult/Add/Permute、置换累加以及 Q/P 提升；保留同类融合。Boot 复用相同短基整数代表元，不从 Q 任意重构 P。
- 独立 sum 避免旧置换累加回退的首项未写回与输出别名问题；N16/N17 的 Q/QP 针对性测试及完整 Boot 均通过。
- KMS 使用 4 MiB staged I/O、损坏 checksum 和同盘原子目录发布；没有 GDS、压缩、并行 I/O或密钥按需换出。详情见[KMS 文档](kms.md)。
- 50 GB 数据盘按模型顺序生成/加载/回收临时密钥包，归档每文件大小、哈希和 manifest；不同时保存十份大包。
- auto 预算预留 4 GiB 且未计入固定 bin 的全部可复用空间，可能保守选择 stream。ResNet56 补做强制 pre 严格矩阵；两种模式原始结果分开保留。
- 计时与误差数据来自当前硬件和有限回归样本，不跨模式拼接均值、不放宽精度门槛、不把分配量或内存池保留空间当作 DRAM 流量。
