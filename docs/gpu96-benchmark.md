# 96 GB GPU：十个真实 CIFAR-10 模型测评

2026-10-30，十个模型均完成真实密文整网测评，全部采用整网预编码 `pre`。
每个模型使用同一组 CIFAR-10 测试图 0–10，共 11 张；图 0 预热，图 1–10 统计性能。
共执行 110 次密文推理。同多项式逐层实部/虚部 `1e-2` 门槛全部通过，没有放宽门槛、裁剪激活或调整既有范围。

本次使用本地原始 ONNX 导出的真实 FP32 权重，ResNet20 也使用本地 ONNX，
不使用先前公开 AE ResNet20 权重或合成权重。VGG16 来自
`~/Downloads/vgg16_cifar10.onnx`；它与已有 ACE 目录中的文件 SHA256 一致。
输入归一化为 mean `[0.485,0.456,0.406]`、std `[0.229,0.224,0.225]`。

小模型同样显示约 47.77 GiB，是因为本次 RMM 的 cuda_async_memory_resource
默认以 `free / 2` 预热 CUDA 内存池，并默认将释放阈值设为总显存。
该占用包含空闲保留空间，不能视作模型的最低显存需求。
源码证据保存在本地 `validation/gpu96-20261030/rmm-cuda_async_memory_resource.hpp` 第 121–130 行。
本轮没有改变 RMM 策略，因此十个模型使用相同分配策略。

本次最高采样值为 VGG16 的 80.96 GiB，低于可见的 95.59 GiB 总容量。
这是逐个模型整网预编码的结果，不代表十个模型可同时常驻。

## 密文与明文误差

先核对导出与明文实现：十个模型的 C++ 普通 ReLU 输出，与原始 ONNX 的独立 PyTorch
float64 输出最大差为 **2.78e-11**，低于 `1e-7` 独立参考门槛。

下表误差在每模型全部 11 张图的 110 个 logits 上计算，使用原始实数单位。
同多项式比较主要反映同态计算误差；普通 ReLU 比较还包含激活多项式近似误差。

| ResNet44 | 6.81608e-4 | 1.19877e-4 | 0.0212695 | 0.00450112 |

通过同多项式 `1e-2` 校验不代表 FHE 与普通 ReLU 的 logits 差也小于 `1e-2`；
VGG16 的 0.2621 主要由激活近似贡献，不能归因于同态计算本身。

## 数据、复现与证据

测试数据来自 [University of Toronto Computer Science 的 CIFAR-10 数据集](https://huggingface.co/datasets/uoft-cs/cifar10/blob/main/plain_text/test-00000-of-00001.parquet)。
官方压缩包下载过慢后，使用该公开 Parquet 的 PNG 像素无损还原完整二进制测试集。
还原后的 30730000 字节 `test_batch.bin` SHA256 为
`8e2eb146ae340b09e24670f29cabc6326dba54da8789dab6768acf480273f65b`，
与此前原始官方二进制完全一致。Parquet SHA256 为
`841389e6f2d64f28bf17310e430aebac20ec3ba611a3c5e231dc93c645ce84de`。

复现每个模型的统一入口，例如：

```bash
time -p python scripts/run_inference.py --model resnet110 \
  --weights /data/models/resnet110.bin --cifar /data/test_batch.bin \
  --count 11 --warmup 1 --encode-mode pre --log-format json
```

其他模型只需替换 model 和 weights。更新源码后先重新编译。
服务器测评目录为 `/root/autodl-tmp/fboot-eval-20261030`，源码在 `cheddar-fhe/`，
权重在 `models/`，原始测评输出在 `results/`。

本地完整证据在被 git 忽略的 `validation/gpu96-20261030/`：

- `summary.json` / `summary.csv`：时间、显存、误差、top-1 及各推理子项。
- `timing_breakdown.csv`：正式单图均值的全部互斥计时子项，单位秒。
- `logits.csv`：1100 行逐类别 FHE、同多项式、C++ ReLU、独立 Torch ReLU 输出及绝对误差。
- `results/benchmark.json`：所有模型的原始参数、资源、11 图结果、计时及实际二进制哈希。
- `results/*.log` / `*-memory.csv` / `*-time.txt`：原始日志、显存采样、外部 time 结果。
- `reference/float-*.json`：原始 ONNX 的独立明文输出。
- `model_sources.json` / `model_sha256.json`：每个实际 ONNX 与导出权重的哈希关联。
- `source_manifest.json` / `source.tar.gz` / `working-tree.patch`：源码快照与当前未提交补丁。
- `benchmark.py` / `analyze.py`：运行和校验过程。

实现代码和本页摘要随分支保存；原始权重、数据及日志保留在本地忽略目录中。
服务器在测评结束后保持空闲。
